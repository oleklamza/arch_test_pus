# System rezerwacji przestrzeni biurowych _InvadeSpaces_

## Ogólny opis
Firma zajmująca się krótko- i długoterminowym wynajmem przetrzeni biurowych potrzebuje oprogramowania wspomagającego
zarządzanie rezerwacjami.

Podczas wstępnej rozmowy na temat wymagań udało się zanotować tyle:
- czas trwania rezerwacji musi wynosić od pół godziny do 8 godzin,
- rezerwacja musi dotyczyć terminu w przyszłości,
- sala nie może mieć dwóch nakładających się rezerwacji,
- rezerwacja może rozpocząć się wyłącznie o pełnej godzinie lub o półgodzinie,
- godziny pracy muszą się mieścić w zakresie od 7 rano do 19.

## Kluczowe zagadnienia

**AO:**
- precyzowanie wymagań funkcjonalnych i niefunkcjonalnych
- opracowywanie specyfikacji systemu
- architektura warstwowa i jej warianty
- alternatywne rozwiązania, np. architektura heksagonalna

**TO:**
- techniki projektowania testów, m.in.:
  - klasy równoważności
  - wartości brzegowe
  - tablice decyzyjne
  - przejścia między stanami
  - kombinatoryka (pairwise)
  - eksploracja
- zastosowanie heurystyk w opracowywaniu testów
- podział testów: jednostkowe/integracyjne/API/E2E

**PUS:**
- podstawy Spring Boot
- budowa aplikacji w architekturze warstwowej
- tworzenie testów jednotkowych i integracyjnych
